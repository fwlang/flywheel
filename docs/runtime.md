# Runtime and ownership

LLVM values hold primitive numbers and booleans directly. Immutable UTF-8 strings, dynamic arrays, tuples, maps, class instances, Results, JSON documents, errors, and markup nodes are heap objects with atomic reference counts. Object slots, map keys, and element children retain references. Assigning a collection or instance aliases it; mutations are visible through both bindings. String concatenation produces a new string.

Generated functions establish an ownership frame. Reference locals and parameters have initialized owning roots. Stores retain the new reference before releasing the previous value. Lexical scope exit clears local roots, including exits through exceptions, break, and continue. Parameters and returned references remain valid through function calls. Normal and error returns drop the frame; roots already cleared at scope exit are harmless null entries.

Temporary references remain alive through their statement and are drained at safe boundaries. A conservative analysis skips temporary retains for reads in expressions containing only known non-mutating operations. User callbacks, function-valued calls, collection mutations, unknown methods, and custom `.render()` methods retain protection. This preserves left-to-right behavior when a nested call replaces the original variable, array item, map value, or instance field. `pop()` protects an object result before removing the array slot.

`for` evaluates the iterable once. Array iteration captures the initial length; map iteration uses a key snapshot. The iterable's hidden root is released after the loop. Return values and pending errors have protected roots while `finally` runs. Those roots are released if a new exception or loop exit abandons the original transfer. An inner catch within a finalizer does not prematurely release the pending return/error.

Native C++ failures are caught at runtime C ABI boundaries and recorded in a thread-local typed error channel. Generated code checks the channel after fallible native and generated calls. Failure edges release crossed scopes and temporary values before dispatching catches or propagating through the caller. C++ exceptions do not unwind through generated LLVM functions. `finally` executes along each applicable normal/error/control-flow path. Uncaught errors report to stderr and return exit status 1.

`testing.live_objects()` reports the current number of live managed objects, enabling lifetime regression checks; it does not count ownership frames or all C++ allocations. AddressSanitizer/UBSan tests exercise both standalone programs and imported projects.

Reference counts remain atomic. This does not make mutable arrays, maps, or class fields safe for concurrent mutation; parallel language execution is not enabled. Strong cycles are not collected, and `weak<T>` remains unimplemented. Full escape analysis, stack allocation of managed objects, general move optimization, and automatic cycle handling are not claimed.

Markup is constructed by compiled native calls, with no runtime XML parser. Fragments preserve their sequence of children and serialize without a wrapper. `element` can hold either a named element or a fragment; this compatibility does not turn the fragment into a named tag. Both support `.render()`, and formatting uses the same HTML serializer as explicit `html.render`. Serialized strings are ordinary managed strings. Text/attribute escaping and source entity decoding remain unchanged.

HTTP listeners own copies of their route strings and native handler references independently of the function that registered them. `web.serve` returns an ARC-managed URL string after successful binding. The generated entry point runs the serial HTTP loop before dropping global roots, so callbacks can read initialized application globals. Listener/client sockets use native RAII cleanup, and each returned handler tree is released after serialization or failure. Startup and propagated handler errors close the appropriate sockets before ordinary frame cleanup.

Managed slots carry a compact value-kind tag for recursive formatting and checked collection conversion. Classes include compiler-generated field-name/type identity metadata; formatting never executes user methods or interprets source ASTs. Sequence casts/repetition copy outer containers and retain same-typed nested objects. Query results and attribute/child snapshots use normal ARC references; cycle-creating markup insertion is rejected before mutation. CSS selector parsing operates on native element values without reparsing HTML.

Terminal input returns an ordinary ARC-managed string. Native child processes run synchronously without executing Flywheel callbacks. Pending stdout/stderr are flushed before spawning; children inherit standard streams, environment, and working directory. POSIX uses `posix_spawnp`/`waitpid` with interrupted waits retried; Windows uses UTF-16 `CreateProcessW` and RAII-owned process/thread handles. No Python runtime is involved. Input/process failures use the normal typed error channel and temporary cleanup.

Desktop windows are ARC-managed descriptions containing a title, dimensions, and a serialized HTML snapshot. Loading markup retains no source tree. `run` loads the optional backend through its versioned C ABI, creates a native webview with RAII lifetime, and returns after closing it. Backend failures are translated into `DesktopError` before returning to generated code. Native GUI dependencies are separate from the core runtime and loaded only by `run`.
